Fast fertig — noch eine kleine Einrichtung

Damit alle in der Familie denselben Einkaufszettel und dieselbe Merkliste sehen, braucht diese Seite eine eigene, kostenlose Cloud-Datenbank (Firebase). Das machst du einmalig:

  1. Auf console.firebase.google.com mit deinem Google-Konto ein neues Projekt anlegen (z. B. „marktvergleich-bernhausen").
  2. Im Projekt links auf Build → Firestore Database → Datenbank erstellen und den Testmodus wählen.
  3. Links auf Build → Authentication → Los geht's, Anbieter E-Mail/Passwort aktivieren und darin den Schalter „E-Mail-Link (Anmeldung ohne Passwort)" einschalten.
  4. Unter Authentication → Settings → Authorized domains die Adresse deiner späteren Webseite eintragen (z. B. dein-name.github.io) — sonst funktioniert der Anmelde-Link dort nicht.
  5. Zurück im Projekt-Überblick auf das Web-Symbol (</>) klicken und eine App registrieren (Name egal, „Firebase Hosting" kann abgewählt bleiben).
  6. Den angezeigten firebaseConfig-Block kopieren.
  7. Im HTML-Code dieser Seite die Zeile var FIREBASE_CONFIG = { ... }; suchen, durch den kopierten Block ersetzen.
  8. Direkt darunter bei var ALLOWED_EMAILS = [...] die E-Mail-Adressen eintragen, die Zugriff haben sollen, dann die Datei speichern.

Im Reiter Regeln der Firestore-Datenbank diesen Text einfügen und veröffentlichen, damit nur angemeldete, freigegebene Adressen lesen & schreiben dürfen (die E-Mails hier müssen zu ALLOWED_EMAILS oben passen):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /state/{docId} {
      allow read, write: if request.auth != null
        && request.auth.token.email in [
          'DEINE_EMAIL@beispiel.de'
        ];
    }
  }
}

Erst mit diesen Regeln ist der Zugriff wirklich auf die eingetragenen Adressen beschränkt — die Liste in ALLOWED_EMAILS im Code sorgt nur für die passende Ansicht, schützt die Daten aber allein nicht.
